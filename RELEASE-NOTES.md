# MarineGPS 1.0.0 candidate

Offline GNSS, compass, waypoints, routes, TrackBack, recording, regional historical wreck catalogue, fishing tools, anchor monitoring and backup/share. Arabic and English interfaces. Upgrade using the same signing identity; export a backup first. Allow precise location and notifications, and verify battery settings. Anchor monitoring is an aid, not a safety guarantee. Historical wreck coordinates are not safe destinations. Field validation remains required before stable release. Backup restore across separate databases is not atomic.
